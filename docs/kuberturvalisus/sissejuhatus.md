# Küberturvalisus

::: info Tulemus
Pärast seda osa oskad ära tunda peamised küberturvalisuse riskid (nõrgad paroolid, phishing, pahavara, ebaturvaline Wi-Fi) ja rakendada lihtsat turvakontrolli nimekirja oma seadmetele.
:::

See on aine "Arvutivõrgud ja küberturvalisus" teine ja viimane osa. See eeldab, et [Võrgu aluste](/arvutivorgud/sissejuhatus) osa (seade, võrk, IP-aadress, kuidas kohalik võrk internetiga ühendub) on juba läbitud — turvariskidest (nt ebaturvaline Wi-Fi) on lihtsam rääkida, kui teed juba oskad, mida need mõisted tähendavad.

## Seos teiste teemadega

Turvariskide näited (nt ebaturvane Wi-Fi) viitavad tagasi [Võrgu aluste](/arvutivorgud/sissejuhatus)-osale, kus need mõisted juba selgeks said.
