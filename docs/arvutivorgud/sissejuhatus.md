# Arvutivõrgud ja küberturvalisus

::: info Tulemus
Pärast seda osa oskad kirjeldada, millistest seadmetest koosneb tavaline kodu- või koolivõrk, mis on IP-aadress ning kuidas andmepakett liigub sinu seadmest sihtkohani.
:::

See on aine "Arvutivõrgud ja küberturvalisus" esimene osa. Enne turvalisuse juurde minekut tasub aru saada, mis on võrk üldse, kuidas seadmed omavahel suhtlevad ning kuidas kohalik võrk laiema internetiga kokku käib.

Aine koosneb kahest osast:

1. **Võrgu alused** (see osa) — mis on arvutivõrk, seadmed, pakettide liikumine ning kuidas see kõik internetiga ühendub
2. **[Küberturvalisus](/kuberturvalisus/sissejuhatus)** — riskid, paroolid, phishing, pahavara
