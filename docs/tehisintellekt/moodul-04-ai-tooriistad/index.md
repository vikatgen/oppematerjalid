# AI tööriistad

Neljandas moodulis vaatame, milliste konkreetsete tööriistadega tänapäeval igapäevaseid äriülesandeid toetatakse. Moodulis 3 õppisime, kuidas AI-le hästi promptida — nüüd vaatame, **milliste tööriistadega** seda tehakse: vestlusassistendid, otsingu- ja uurimistööriistad, loovsisu (pilt/video/heli) tööriistad ning kontoritöösse sisse ehitatud AI.

Mooduli lõpuks oskad eristada peamisi tööriistakategooriaid ja valida konkreetse ärivajaduse jaoks sobiva tööriista, tuginedes [tunnis 1.3](/tehisintellekt/moodul-01-mis-on-ai/tund-03-kus-kasutatakse) tutvustatud ärieesmärkide raamistikule.

::: tip Koodi- ja arendustööriistad
GitHub Copilot, Claude Code ja teised arendustööriistad käsitletakse põhjalikult moodulis 6 ("AI tarkvaraarenduses"). Selles moodulis mainime neid vaid põgusalt.
:::
