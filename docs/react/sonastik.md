# Reacti sõnastik

| Mõiste | Tähendus meie rakenduses |
|---|---|
| Komponent (component) | Funktsioon, mis kirjeldab kasutajaliidese osa, näiteks PostCard |
| JSX | JavaScripti süntaksilaiendus kasutajaliidese kirjeldamiseks |
| Props | Vanema antud komponendi sisendid |
| Children | Komponendi märgendite vahele antud sisu |
| State ehk olek | Reacti hoitud muutuv info, näiteks favoriteIds |
| Renderdus (render) | Komponendi kutsumine uue vaate arvutamiseks |
| Commit | Arvutatud muudatuste rakendamine DOM-is |
| DOM | Brauseri dokumenti esindav objektipuu |
| Hook | use-algusega funktsioon Reacti võimaluste kasutamiseks |
| Efekt (effect) | Välise süsteemiga sünkroonimine pärast commit'i |
| Cleanup | Eelmise efekti seadistuse lõpetamine |
| Sõltuvused (dependencies) | Efektis kasutatud reaktiivsed väärtused |
| Callback | Teisele funktsioonile või komponendile antud funktsioon |
| Muutmatus (immutability) | Uue massiivi või objekti loomine vana muutmise asemel |
| Tuletatud väärtus | Olemasolevatest andmetest arvutatav tulemus, näiteks lemmikute arv |
| Key | Loendi elemendi stabiilne identifikaator Reacti jaoks |
| Kontrollitud väli | Vormiväli, mille value või checked tuleb Reacti state'ist |
| REST API | HTTP kaudu kasutatav andmeteenus |
| JSON | Tekstipõhine andmevorming API päringus või vastuses |
| SPA | Rakendus, mille vaated võivad vahetuda sama HTML-dokumendi sees |
| Marsruut (route) | URL-i mustri ja vaate seos |
| Parameeter (param) | URL-is muutuv väärtus, näiteks postId |
| Outlet | Koht ühises paigutuses sobiva alamlehe kuvamiseks |
| Kohandatud Hook | Meie kirjutatud Hook korduva loogika jagamiseks |
| Build | Lähtekoodist avaldamiseks sobivate failide koostamine |
| Refaktoreerimine | Koodi korralduse muutmine käitumist säilitades |

Kui mõiste jääb segaseks, leia oma projektist üks vastav näide. Selgitus „state on meie favoriteIds, mida toggleFavorite uuendab” näitab rohkem arusaamist kui definitsiooni kordamine.
